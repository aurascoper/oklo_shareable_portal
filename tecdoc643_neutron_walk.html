What happened on Oct 14, in plain words

Claude Code spent an afternoon building a neutron viewer for the real model

You gave Claude Code a long brief and let it work alone for about three and a half hours on a side branch. It built a full-physics version of this page using the actual OpenMC model, checked its own physics along the way, and never touched the main model or pushed anything.

Step 1

Tracked real neutrons. It ran OpenMC with particle tracking turned on, so every neutron's path through the full 3-D core got recorded.

Step 2

Labelled how each one ended. OpenMC's own "fission" flag only means a new neutron was created, so it re-checked each absorption with the real cross sections to label it fission or capture honestly.

Step 3

Checked itself. Its labels reproduce OpenMC's own k-eff (within 1.1σ), and rebuilding everything from scratch gives the exact same 1,571 numbers.

Step 4

Built things to look at. Rotatable 3-D track scenes, four single-neutron "stories", flux and power maps, and a dashboard, all saved locally in viz_out/.

Step 5

Found an OpenMC quirk. OpenMC's 3-D voxel export is shifted half a voxel up. It wrote a small test case proving it. Nothing was reported upstream yet.

About 20% of neutrons in the real model are absorbed in the pool water around the core, while true leakage to vacuum is about 0.03%. The pool acts as a reflector and soaks up most neutrons that wander out. This toy lands at about 23% and 0.1%.
